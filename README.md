# ボードゲーム広場

チェス・将棋・ゴブレットゴブラーズ・五目並べ・オセロ・ワードバスケット・キャット＆チョコレート（風の大喜利ゲーム）・UNO・ワンナイト人狼・ito・大富豪・ポーカー・ブロックス・みんなでポンコツペイント・スカル・軍儀をブラウザでオンライン対戦できるアプリです。

## 起動

```bash
npm install
npm start
```

http://localhost:3000 を開きます（ポートは環境変数 `PORT` で変更可）。

## 遊び方

1. 名前を入力し、ゲームを選んで「部屋を作る」（または手番を指定）
2. 「招待リンクをコピー」して相手に送る（部屋コード入力やロビーの一覧からも参加可）
3. 席が埋まっている部屋に入ると観戦になります（多人数ゲームは参加者がそろったらホストが「ゲーム開始」。開始後に来た人は観戦）
4. 終局後は「再戦する」で先後を入れ替えてもう一局

ページを再読み込みしても同じタブなら自分の席に戻れます。

## 感想戦（チェス・将棋）

終局後に「感想戦をする」を押すと、部屋の全員で同じ盤を見ながら局面を戻したり進めたり（⏮ ◀ ▶ ⏭・棋譜の手をクリック）、盤で駒を動かして別の手（変化）を試したりできます。「本譜に戻る」で変化を消し、「感想戦を終わる」で終局の画面に戻ります。操作できるのは対局者だけで、観戦者は見るだけです。

## 構成

- `server.js` — 静的ファイル配信と WebSocket（`ws`）による部屋管理
- `public/games/*.js` — 各ゲームのルール（サーバーとブラウザで共通）
- `public/app.js` / `style.css` / `index.html` — 画面
- `test/rules.test.js` — ルールのテスト（`npm test`）

## インターネット越しに遊ぶには

同じ Wi-Fi 内なら `http://<このPCのIPアドレス>:3000` で他の端末から接続できます（Windows ファイアウォールの許可が必要な場合あり）。
外部の人と遊ぶ場合は Render・Railway・Fly.io などの Node.js 対応ホスティングにデプロイしてください。部屋の情報はメモリ上にのみ保存されるため、サーバーを再起動すると消えます。
