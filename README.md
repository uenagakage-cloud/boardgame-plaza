# ボードゲーム広場

チェス・将棋・ゴブレットゴブラーズ・五目並べ・オセロ・囲碁・バックギャモン・ワードバスケット・キャット＆チョコレート（風の大喜利ゲーム）・UNO・ワンナイト人狼をブラウザでオンライン対戦できるアプリです。

## 起動

```bash
npm install
npm start
```

http://localhost:3000 を開きます（ポートは環境変数 `PORT` で変更可）。

## 遊び方

1. 名前を入力し、ゲームを選んで「部屋を作る」（または手番を指定）
2. 「招待リンクをコピー」して相手に送る（部屋コード入力やロビーの一覧からも参加可）
3. 席が埋まっている部屋に入ると観戦になります（ワードバスケット・キャット＆チョコレート・UNO・ワンナイト人狼は参加者がそろったら「ゲーム開始」。開始後に来た人は観戦）
4. 終局後は「再戦する」で先後を入れ替えてもう一局

ページを再読み込みしても同じタブなら自分の席に戻れます。

## ルール実装

| ゲーム | 対応しているルール |
| --- | --- |
| チェス | キャスリング、アンパッサン、昇格（駒を選択）、チェックメイト、ステイルメイト、50手ルール、同一局面3回、戦力不足 |
| 将棋 | 成り（任意・強制）、持ち駒と打つ、二歩、行き所のない駒、打ち歩詰め、詰み、千日手（同一局面4回で引き分け） |
| ゴブレットゴブラーズ | かぶせ、盤上の駒の移動、持ち上げて相手の列が現れたら相手の勝ち、同一局面3回で引き分け |
| 五目並べ | 15×15、黒が先手、盤が埋まったら引き分け。部屋作成時に「禁じ手あり」を選択可能: なし＝5つ以上で勝ち／あり＝黒は三三・四四・長連が打てず、ちょうど5つで勝ち（白は長連でも勝ち）。禁じ手の点は盤上に×で表示 |
| オセロ | 8×8、黒が先手、はさんだ石を裏返す、打てる場所がなければ自動パス、両者打てなくなったら石の数で勝敗。石数をプレイヤー欄に表示 |
| 囲碁 | 19路・13路・9路を部屋作成時に選択。日本ルール（地＋アゲハマ）、コミ6目半。石の取り、自殺手の禁止、コウ。2回連続パスで終局処理に入り、死に石をクリックで指定して両者が合意すると勝敗確定（「対局再開」で打ち続けることも可能） |
| バックギャモン | ダイスはサーバーが振る。ゾロ目は4回、ヒットとバーからのエントリー、ベアオフ（大きい目で奥から上がる）、ダイスは使える限り使う・片方だけなら大きい目を優先、動かせなければ自動パス。シングル／ギャモン／バックギャモン勝ちを表示（ダブリングキューブはなし） |
| ワードバスケット | 2〜6人・早い者勝ち。場の文字で始まり手札の文字で終わる3文字以上の言葉を出す（カタカナ可、濁点・小さい文字は清音扱い、「ー」で終わる語は直前の文字）。「ん」終わり・同じ言葉の再使用は不可。行カード・文字数カードあり。言葉の正誤は判定せず、他の人が「ダメ！」で直前の言葉を取り消せる（出した人はカードを戻して1枚引く）。誰も出せないときは全員の投票で場を流す。山札から1枚引く・手札リセット（全部捨てて元の枚数＋1枚引き直す）もいつでもできる。手札がなくなった人の勝ち。相手の手札はサーバー側で隠す |
| キャット＆チョコレート | 2〜6人のチーム戦（ねこ／チョコ、自分のチームだけ見える）。手番の人はピンチを手札のアイテムを指定数使って解決する方法を文章で書き、ほかの全員が成功／失敗を投票（成功が過半数で獲得、同数は失敗）。使ったアイテムは捨てて補充（アイテムは180種類）。全員が2回ずつ手番をしたら終了し、チームの獲得数で勝敗。イベント・アイテムのカード文はこのアプリのオリジナル |
| UNO | 2〜6人、108枚・手札7枚。色か数字/記号を合わせて出す。スキップ・リバース（2人ならスキップと同じ）・ドロー2・ワイルド・ワイルドドロー4（場の色を持っていないときだけ）。出さないときは1枚引き、引いたカードが出せればそのまま出すかパス。残り1枚で「UNO!」を宣言しないと、次の人が動く前に指摘されて2枚引く。先に手札がなくなった人の勝ち（得点計算・ドローの重ねがけはなし）。相手の手札はサーバー側で隠す |
| ワンナイト人狼 | 3〜6人。役職は人数＋2枚（人狼×2・占い師・怪盗・村人、5人以上は狂人も）、2枚は中央。夜は全員同時に行動（人狼は仲間を知る／1人なら中央1枚、占い師は1人か中央2枚、怪盗は交換して新しい役職を知る。占い師は交換前のカードを見る）。昼はチャットで話し合い、全員が投票（自分以外・変更可）。最多得票が処刑（同数は全員、全員1票ずつなら処刑なし）。夜明け後のカードで勝敗判定。終了後に全員の役職・夜の行動・中央のカードを公開 |

共通: 投了、引き分けの提案、チャット。手の正しさはサーバー側でも検証しています。

## 構成

- `server.js` — 静的ファイル配信と WebSocket（`ws`）による部屋管理
- `public/games/*.js` — 各ゲームのルール（サーバーとブラウザで共通）
- `public/app.js` / `style.css` / `index.html` — 画面
- `test/rules.test.js` — ルールのテスト（`npm test`）

## インターネット越しに遊ぶには

同じ Wi-Fi 内なら `http://<このPCのIPアドレス>:3000` で他の端末から接続できます（Windows ファイアウォールの許可が必要な場合あり）。
外部の人と遊ぶ場合は Render・Railway・Fly.io などの Node.js 対応ホスティングにデプロイしてください。部屋の情報はメモリ上にのみ保存されるため、サーバーを再起動すると消えます。
