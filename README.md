# ゲームいっぱい

チェス・将棋・ゴブレットゴブラーズ・オセロ・ワードバスケット・キャット＆チョコレート（風の大喜利ゲーム）・ito・大富豪・ポーカー・ブロックス・みんなでポンコツペイント・スカル・軍儀・どうぶつタワーバトル・ヒット&ブロー・ドット&ボックス・朝からそれ正解・ガイスター・マンカラ・四目並べ・ハゲタカのえじき・一致するまで終われまテンをブラウザでオンライン対戦できるアプリです。『世界のアソビ大全51』に入っているゲームから、ナインメンズモリス・ヘックス・チェッカー・ドミノ・チャイニーズチェッカー・ルドー・7ならべ・スピード・神経衰弱・ブラックジャック・ラストカード・ぶたのしっぽ・ヨット・花札（こいこい）・VSタンク・ヒット&ブロー（ボール）も遊べます（ロビーの「アソビ大全から」）。アクションゲームの「ディノラッシュ」「ソウルバレッジ」「関節ウォーカー」「洞窟脱出ジャンプ」も遊べます。

## 起動

```bash
npm install
npm start
```

http://localhost:3000 を開きます（ポートは環境変数 `PORT` で変更可）。

## 遊び方

1. 名前を入力し、ゲームを選んで「部屋を作る」（または手番を指定）
2. 「招待リンクをコピー」して相手に送る（部屋コード入力やロビーの一覧からも参加可）
3. 席が埋まっている部屋に入ると観戦になります（多人数ゲームは参加者がそろったらホストが「ゲーム開始」。開始後に来た人は観戦）
4. 終局後は「再戦する」で先後を入れ替えてもう一局

ページを再読み込みしても同じタブなら自分の席に戻れます。

## 感想戦（チェス・将棋）

終局後に「感想戦をする」を押すと、部屋の全員で同じ盤を見ながら局面を戻したり進めたり（⏮ ◀ ▶ ⏭・棋譜の手をクリック）、盤で駒を動かして別の手（変化）を試したりできます。「本譜に戻る」で変化を消し、「感想戦を終わる」で終局の画面に戻ります。操作できるのは対局者だけで、観戦者は見るだけです。

## 開けないときの対策

- 文字のファイルは gzip で圧縮して送り、変わっていないファイルは 304 で再利用する（弱い回線でも読み込みやすく）。
- 並べ替えに使う SortableJS は外部サイトではなく public/vendor から配る。
- 8秒たっても画面が動き出さないときや、ファイルを読み込めなかったときは、上に「読み込み直す」ボタンと案内（Discord のアプリ内ブラウザなら方位磁針のマークで Safari で開く、など）を出す。
- LINE のアプリ内ブラウザで開いたときは、URL に openExternalBrowser=1 を付けて Safari / Chrome で開き直す。招待リンクにも最初から付ける。

## ディノラッシュ（アクション）

Chrome の恐竜ゲーム風のリアルタイムアクション（元は別アプリの dino-rush）。しくみがターン制のゲームと違うので、`dino/` フォルダにまるごと入れて、同じサーバーの `/dino/` で動かしています（WebSocket は `/dino/ws`、ランキングは `/dino/api/ranking`）。ロビーの「アクション」から開けます。

- ソロレース（ランキング）・マルチレース（おじゃまアイテム）・バトル（チーム戦・CPU あり）
- ランキングは環境変数 `DATABASE_URL`（PostgreSQL）があればそこに、なければ `data/scores.json` に保存（無料プランでは再起動で消える）
- テスト: `npm run test:dino`
- 詳しくは `dino/README.md`

## ソウルバレッジ（アクション）

Undertale 風のオンライン弾幕サバイバル（元は別アプリの soul-barrage）。Express と socket.io で動く CommonJS のサーバーなので、`soul/server.cjs` にして同じサーバーの `/soul/` に取り付けています（socket.io は `/soul/socket.io`）。ロビーの「アクション」から開けます。

- ソロ・バトルロイヤル・5ステージのボスを倒すストーリー（協力）、難易度5段階
- 単体でも `node soul/server.cjs` で動きます
- 詳しくは `soul/README.md`

## 関節ウォーカー・洞窟脱出ジャンプ（ひとり用アクション）

どちらもサーバーを使わない1ページのゲームで、`public/walker/` と `public/cave/` にあります（`/walker/`・`/cave/` で開く）。ロビーの「アクション」から開けます。ベストタイムはその端末に保存されます。

- 関節ウォーカー: 股関節・膝・足首を1つずつ動かして50m歩く。物理は planck.js（CDN）。スマホでは左下に左脚、右下に右脚のボタンが出て、両手で同時に押せる
- 洞窟脱出ジャンプ: 力をためてジャンプし、全10層の洞窟を登る。スマホでは左下に ◀▶▲▼、右下に長押しジャンプのボタンが出る（横画面がおすすめ）

## ラウンジ

ロビーの上にある、みんなが集まって話せる場所です。

- 今つながっている人と、その人がどこにいるか（ロビー・どのゲームで遊んでいる／待っている）が見えます。遊んでいる人を押すと、その部屋に入れます（始まっていれば観戦）。
- 全員で話せるチャットがあり、ロビーにいる間は画面にも流れます（最新100件までサーバーのメモリに残り、再起動で消えます）。
- 部屋の中の「ラウンジで誘う」を押すと、ラウンジに「参加する」ボタン付きのお誘いが出ます（同じ部屋は30秒に1回まで）。

## 手札などの公開

- カードゲームなど隠れた情報があるゲーム（大富豪・ポーカー・ワードバスケット・キャット＆チョコレート・スカル・ハゲタカのえじき・ito）は、終わったあとに全員の手札（コースター・数字）を公開します。
- 観戦者と、先に上がった人・脱落した人・投了した人（ポーカーで降りた人も）は、遊んでいる途中でも全員の手札が見えます。
- ブロックスは、ほかの色の残りのピースもいつでも見られます。

## 途中で抜けたとき

- ゲームの途中で「← ロビー」を押したり、アプリやブラウザを閉じたりしても席は残ります。戻ると同じ席・同じ手札から続けられます。ただし遊んでいる人（CPU以外）がだれもつながっていない部屋は、20秒たつと消えます（部屋の一覧からはすぐ消えます）。
- 端末ごとの ID（localStorage）を覚えているので、タブやアプリを閉じて開き直しても同じ席に戻れます。別のブラウザで開いたときも、同じ名前なら戻れます（その席の人が接続していないときだけ）。
- ロビーの上に「▶ ○○の部屋に戻る」ボタンが出ます。

## チャット・ホストの操作

- チャットはニコニコ動画のように画面を右から左へ流れます（チャット欄の「コメントを流す」で ON/OFF）。右下の 💬 からどの画面でもすぐ書けます。
- 部屋を作った人（ホスト）は、ロビーでもゲーム中でも、プレイヤーの名前をタップするとその人を追い出せます。追い出された人はその部屋に入れなくなります。2人用のゲームでは対局を最初からにして新しい相手を待ち、多人数のゲーム中はその人が脱落になります。CPU は追い出せません。

## 構成

- `server.js` — 静的ファイル配信と WebSocket（`ws`）による部屋管理
- `public/games/*.js` — 各ゲームのルール（サーバーとブラウザで共通）
- `public/app.js` / `style.css` / `index.html` — 画面
- `public/asobi-ui.js` / `asobi.css` — アソビ大全から入れたゲームの画面
- `test/rules.test.js`・`test/asobi.test.js` — ルールのテスト（`npm test`。アソビ大全のゲームは全員 CPU で最後まで遊ぶテストもする）

## インターネット越しに遊ぶには

同じ Wi-Fi 内なら `http://<このPCのIPアドレス>:3000` で他の端末から接続できます（Windows ファイアウォールの許可が必要な場合あり）。
外部の人と遊ぶ場合は Render・Railway・Fly.io などの Node.js 対応ホスティングにデプロイしてください。部屋の情報はメモリ上にのみ保存されるため、サーバーを再起動すると消えます。
